# 2026-10-27

## 投资情报与动态资产配置系统（全新项目）

从 `信息差.md` 任务书从零实现完整系统，工作区此前只有该文档。

**架构**
- 后端：FastAPI + SQLAlchemy 2 + SQLite，25 张表，`backend/app` 下分 api/providers/models/services/ai/jobs/core。
- 前端：Vue 3 + Vite + TS + ECharts，10 个页面（总览/机会雷达/事件/目录/单品/配置/宏观/回测/数据源/设置），浅色金融工作台风格。
- 配置驱动：`config/asset_classes.yaml`、`instruments.yaml`、`data_sources.yaml`、`signal_rules.yaml`、`risk_limits.yaml`。

**真实数据源（实测）**
- 新浪行情 `hq.sinajs.cn`（GBK，需 Referer）：A股/ETF/港股/美股指数/COMEX 金银/原油/汇率。
- 日线：东方财富不稳定（高频后断连），实现 东方财富→腾讯→新浪 回退 + 熔断；外盘走新浪 GlobalFuturesService。
- 新闻：东方财富 np-listapi（80 条/次）。
- 宏观：世界银行 API（90 条年度观测，并发 4）。
- 未配置但已登记：FRED、Tushare、AKShare、GDELT。

**关键算法**
- 事件：标题哈希去重 → difflib + 前缀/包含规则聚类 → 关键词分类 → 重要性/置信度 → 证据 + 传导 + 资产关联 + 版本快照。
- 评分：模块化权重，缺失特征剔除并降 coverage；价格序列 <60 条直接“暂不判断”。
- 配置：基础权重 + 战术倾斜 → 有界单纯形投影（对偶二分）→ 换手上限 → 最小交易阈值。
- 回测：只使用价量信号避免宏观前视偏差，成本/换手/样本内外，异常日收益 >40% 中止。

**踩坑与修复**
1. 配置接口 500：JSON 含 NaN → `clean_json`。
2. 二级类别用 `split("_")` 归并错误（CN_EQ_INDEX→CN）→ 改为层级映射 `top_class_map`。
3. 回测收益爆炸：对“当日各资产价格”做 pct_change → 改为预计算收益矩阵。
4. 前端 `/assets/:symbol` 被 StaticFiles `/assets` 抢占 → 去掉 mount，SPA catch-all 优先返回真实文件，且 `/api/*` 显式 404。
5. 示例持仓只建 1 条（循环内 break）→ 按品种判重，补齐 8 条。
6. pip：默认清华镜像不可用，需 `-i https://pypi.org/simple`；`uvicorn[standard]` 在 Windows 安装极慢，改为 `uvicorn`。
