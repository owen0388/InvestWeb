## 1b ETF 质量分 v0 + 1a-4 覆盖可视化（完成）

### 质量分设计
四项指标，横截面分位（0–100）+ 缺失归权 + 覆盖率 <50% 整项停用：
- 流动性 40%：当日成交额（**1d 口径，未用日线反推**，因腾讯 volume 是"手"、新浪是"股"，差 100 倍）
- 规模 30%：f20 市值口径
- 折溢价稳定性 20%：近 60 日 |价格/净值−1| 中位数，**必须同日匹配**，样本 ≥20
- 历史长度 10%：日线根数

跟踪误差**没做**——需要指数序列，免费源没有。用净值怼价格得到的是折溢价波动，不是跟踪误差，不能混称。

置信度 = 可用权重占比（货币类 0.8，因不算折溢价）。质量分与"标的吸引力"严格分离，不合成推荐分。

### 1) 回测五策略对比（3-1）——发现严重 bug

**bug：回测权重从不漂移**。原实现只在调仓日更新权重，调仓日之间保持不变，

## 修复 start.ps1：ParserError（用户首次实际运行暴露）

**我之前一直用 bash 直接跑 uvicorn，从没执行过 start.ps1**，所以这个交付物完全没验证。

**报错**：ParserError: start.ps1:25 Unexpected token 'Add' in expression or statement

**根因**：文件是 UTF-8 无 BOM，第 25 行用了中文弯引号包裹 Add python.exe to PATH（U+201C/U+201D）。
PowerShell 5.1 对无 BOM 脚本按系统 ANSI(GBK) 解码，中文字节序列被错误解析，
某些字节被当成字符串结束符，Add 就成了孤立 token。

**修复**
1. 写 UTF-8 with BOM
2. 弯引号全部替换为书名号，并对第 25 行进一步去掉引号
3. **新增 Python 版本校验**：实测发现用户机器 python 指向 F:\Python27\python.exe。
   原脚本拿到 2.7 也不报错（只因 .venv 已存在才没炸），一旦删 .venv 就会用 py2.7 建环境。
   改为：优先用 .venv\Scripts\python.exe，需要新建时逐个试 python/python3/py 并校验 >=3.11
4. 设置 Console.OutputEncoding 为 UTF8，消除中文提示乱码

**验证**：AST 解析 0 error；实际执行生产模式启动 → 前端构建成功、
13 个定时任务注册、health 200、radar 200。

**教训**：写进 README 的启动脚本必须实际执行一次，-SkipInstall 就能快速验证。
