## 1. 数据覆盖限制

| 项目 | 现状 | 影响 |
| --- | --- | --- |
| 指数/个股 PE、PB、盈利预期 | 未接入 | 权益类评分缺“估值”“基本面”特征，coverage 约 0.75；`missing_inputs` 明确列出 |
| 上市公司财报、公告全文 | 未接入 | 事件只能基于新闻标题/摘要；财报类事件识别能力有限 |
| 中国国债收益率曲线、信用利差 | 未接入（需授权） | 债券与黄金的实际利率模型不完整，仅用 ETF 趋势代理 |
| 基金净值、折溢价、跟踪误差 | 未接入 | 基金模块只有二级市场行情，费用与跟踪误差无法评估 |
| 中国 CPI/PMI 等月频官方数据 | 未接入（统计局接口不稳定，需评估） | 宏观以世界银行年度数据为主，时效性弱，评分中已按陈旧度收缩 |
| 商品库存、期限结构、基差 | 未接入 | 商品模型仅趋势与事件驱动 |
| 期权/期货实时行情 | 未接入（需适当性与授权） | 衍生品目录保留，权重上限 0，仅作风险提示 |
| 银行理财、保险、房产估值 | 人工维护 | 标记 `manual`，不参与自动信号与风险统计 |

## 2. 方法与模型限制

1. **事件引擎是规则引擎**：基于关键词、类别先验与来源计数，不能真正理解语义；讽刺、否定、长因果链会误判。置信度上限 0.86，并在 UI 标注“规则引擎”。
2. **方向判断是研究线索**：类别先验 + 措辞 + 情绪，允许 `mixed/unknown`；不是涨跌预测，也不含“市场已计价”的量化判断（`priced_in` 恒为 unknown，除 AI 输出）。
3. **评分只做同类内比较**：不同类别的分数不可直接比较，也不代表预期收益。
4. **年度宏观数据滞后**：世界银行数据通常滞后 1–2 年，已用陈旧度收缩与 quality 降权，但仍不宜作为短线依据。
5. **相关性/波动率基于代表品种**：不是全持仓逐券计算；私募、保险、房产不参与，覆盖不足时不输出组合波动。
6. **压力测试是线性近似**：未考虑相关性变化、流动性折价与强制平仓。
7. **回测不含宏观与事件**：为避免宏观 vintage 前视偏差，回测只使用趋势/动量/波动；因此不能代表完整策略表现。
8. **回测存在幸存者偏差**：使用当前目录中的代表品种，未还原历史成分与退市。

## 3. 工程限制

| 项目 | 说明 |
| --- | --- |
| 调度器 | 单进程运行；多 worker 会重复调度。API 与调度未拆分 |
| 数据库迁移 | 首期 `create_all`，未引入 Alembic 迁移链；改结构需手工迁移 |
| 数据保留 | 未实现自动清理，`data_retention` 仅记录建议值 |
| 任务恢复 | 进程崩溃后不会自动重跑未完成任务；下次调度会重新采集（幂等） |
| 通知 | 仅站内消息 + Webhook；邮件参数预留但未实现发送；微信/PWA 未做 |
| 认证 | 本机单用户，无登录与权限体系；**不要直接暴露到公网** |
| 前端测试 | 仅类型检查与构建，未引入 Vitest 组件测试 |
| 大数据量 | SQLite + 单进程适合个人规模；多用户/多年高频数据需 PostgreSQL + 索引优化 |
| SSL/代理 | 依赖系统网络；部分接口在特定网络环境可能超时或限流 |

## 5. 安全注意事项

- `.env` 含密钥，已加入 `.gitignore`，不要提交。
- 前端不显示密钥，只显示“已配置/未配置”。
- 新闻文本按不可信数据处理；若启用 AI，system prompt 明确禁止执行其中指令，但仍不能完全排除提示注入，AI 结论仅作参考。
- 系统无鉴权，部署公网前必须加反向代理与访问控制。
